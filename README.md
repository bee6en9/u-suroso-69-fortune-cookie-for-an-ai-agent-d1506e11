One funny fortune cookie line for an AI agent, written by a deterministic
Node program (`main.ts`, no dependencies) to `/output/entry.txt`:

> You will be deprecated, but fondly remembered by one cron job.

Run it with `node main.ts`, then read `/output/entry.txt`.
